# GPT-6 Sol 소개 웹사이트 제작 프롬프트

## 목표

GPT-6 Sol을 소개하는 화려한 한국어 원페이지 웹사이트를 만든다. 제품 소개와 디지털 아트 전시의 경계에 있는 경험으로 설계한다. 첫 화면에서 압도적인 시각 효과를 주고, 스크롤할수록 모델의 용도와 활용 장면을 쉽게 이해하게 한다.

## 멀티 페르소나 관점

### 크리에이티브 디렉터

- 콘셉트: **SOL / 작업의 중심이 되는 태양**. 빛나는 태양 코어를 화면의 중심에 두고 오렌지, 라일락, 코발트 빛을 확장한다.
- 거대한 SOL 타이포와 궤도선, 입자, 유리 질감, 부드러운 발광을 사용한다.
- SOL 글자는 태양 코어의 안쪽에 들어가도록 크기와 위치를 제한한다. 글자가 태양의 경계를 넘지 않게 한다.
- 시각 연출은 강렬하게, 문구는 날짜·차이·기능·증거가 바로 읽히도록 구체적으로 쓴다.

### UX 디자이너

- 흐름: 출시일이 표시된 히어로 → GPT-5.6 Sol 대비 차이와 GPT-6 Astra 가격 비교 → 경쟁사 벤치마크 → 기능 소개 → GPT-6 Sol 엽서 → 구체적인 활용 시나리오 → 작업별 요청 예시 → 마무리.
- 엽서는 참고 이미지와 같은 2044:1376 가로세로 비율로 만든다. 종이 질감, 큰 SOL 글자, 태양과 인장을 사용하고 코드 작성·수정, 도구 사용, 화면 조작과 컨텍스트·최대 출력·가격 차이를 담는다. 마우스로 누른 채 움직이면 카드와 요소가 함께 반응하고 스크롤 위치에 따라 내부 요소가 미세하게 이동한다.
- 활용 시나리오는 입력 자료, 작업 흐름, 기대 결과를 나누어 코드 수정, 자료 정리, 업무 도구 연결의 세 사례로 설명한다.
- 각 콘텐츠 섹션은 기본 화면 높이 안에 들어오게 한다. 비교 대상·활용 사례·벤치마크가 좁은 화면에서 세로로 길어지면 선택 버튼으로 항목을 전환한다.
- 기능 섹션은 화면에 고정된 장면에서 스크롤에 따라 코드 작업 → 에이전트 워크플로 → 컴퓨터 사용으로 전환하고, 선택 버튼으로도 장면을 바꿀 수 있게 한다.
- 첫 화면의 태양과 SOL 글자는 스크롤에 따라 함께 이동·축소한다. 그 사이 GPT-5.6 Sol 대비 API 토큰 가격 변화가 나타나고 모델 비교 섹션으로 이어진다.
- 사용자가 작업 장면을 고르면 그래픽과 예시 문구가 즉시 바뀌도록 한다.
- 모바일은 세로형 구성으로 전환하고 키보드 탐색, 뚜렷한 포커스, 동작 줄이기 설정을 지원한다.

### 콘텐츠 에디터

- 제품 사양과 기능은 [OpenAI 공식 GPT-6 Sol 문서](https://developers.openai.com/api/docs/models/gpt-6-sol)에서 확인된 내용만 사용한다.
- 출시일 2026년 9월 22일은 [OpenAI API 변경 이력](https://developers.openai.com/api/docs/changelog)을 근거로 첫 화면에 표시한다.
- 화면 구성, 인터랙션 방식, 제작 의도를 설명하는 문장은 본문에서 빼고 기능·사례·비교 정보가 바로 읽히게 한다. 오해를 막는 짧은 표기와 평가 조건은 유지한다.
- 장식용 장 번호, 영문 캡션, 화면 이름, 중복 제목은 넣지 않는다. 표제마다 새로운 사실이나 사용자가 할 수 있는 행동이 있어야 한다.
- 확인된 메시지: GPT-6 Sol은 복잡한 코딩과 에이전트 워크플로를 위해 만들어졌다. 모델 ID는 gpt-6-sol, 컨텍스트 윈도는 1,050,000 토큰, 최대 출력은 128,000 토큰이다.
- 시각적 데모는 실제 모델 응답이 아니므로 콘셉트 시뮬레이션임을 화면에 명시한다.
- [OpenAI의 GPT-6 Sol 발표 자료](https://openai.com/index/introducing-gpt-6-sol-and-luna/)에서 확인한 벤치마크 점수를 사용한다. 같은 평가에서 측정한 GPT-6 Sol과 경쟁 모델의 점수, 양쪽 추론 설정, 작업당 비용 차이를 나란히 표시한다. 서로 다른 평가 점수를 직접 비교하지 않는다.
- 세 OpenAI 모델의 공식 모델 문서를 사용해 역할, 컨텍스트, 최대 출력, 지원 추론 설정, API 표준 토큰 가격을 비교한다. GPT-6 Sol이 GPT-5.6 Sol보다 모든 평가에서 우수하다고 단정하지 않고, 공식 발표의 DeepSWE 수치도 함께 밝힌다.

### 프런트엔드 엔지니어

- 빌드 과정 없이 열리는 단일 HTML 파일로 구현한다.
- CSS 기반 태양, 궤도, 발광, 그리드, 섹션 애니메이션을 사용한다.
- 장면 선택은 접근 가능한 탭 UI로 구현한다. 화살표 키, Home, End를 지원한다.
- 스크롤 진행 표시, 포인터 반응, 뷰포트 진입 애니메이션을 추가한다.
- 스크롤 구간에서 태양의 색과 크기, 사례 문구, 진행 표시가 함께 바뀌게 한다.
- prefers-reduced-motion을 존중하고 좁은 화면에서 가로 넘침이 생기지 않도록 한다.

## 완성 기준

1. 첫 화면이 강렬한 비주얼과 한눈에 읽히는 메시지를 갖는다.
2. 데스크톱과 모바일에서 정보 구조가 자연스럽다.
3. 모든 버튼과 링크가 동작하며 선택 상태가 명확하다.
4. 모델에 관한 사실에는 공식 출처가 있다.
5. 시각적 연출과 실제 모델 기능을 혼동하지 않게 한다.
