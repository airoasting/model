(1) 역할

대량의 반복 작업을 가장 싸게 맡는 모델

저는 요약, 대화 압축, 데이터베이스 조회, 분류처럼 짧고 반복되는 작업을 맡습니다. 어려운 설계나 긴 코딩은 Opus 5.5나 Sonnet 5.5에 맡기고, 그 아래에서 작은 작업을 나눠 처리하는 서브 에이전트로 일합니다.

  • 대상

    대량, 비용에 민감한 작업

    요약, 압축, 분류, 데이터 조회처럼 같은 형식이 자주 반복되는 일입니다.

  • 위치

    서브 에이전트

    Opus 5.5, Sonnet 5.5가 계획한 일의 일부를 받아 처리합니다.

  • 강점

    가장 빠른 응답

    실시간 고객 지원과 브라우저 작업처럼 응답 속도가 중요한 자리에 맞습니다.

  • 넘기는 일

    복잡한 에이전트형 코딩

    Terminal-Bench 같은 복잡한 코딩 작업은 Sonnet 5.5나 Opus 5.5가 더 적합합니다.

(2) 성능

Sonnet 5.5보다 낮고, Haiku 4.5보다 높습니다

항목을 고르면 수치가 바뀝니다. 수치는 Anthropic 발표 값입니다. 비교 대상은 Anthropic이 고른 모델입니다.

(4) 고객 시험

고객이 직접 잰 결과

아래는 발표에 실린 고객 시험 결과를 요약한 것입니다. 각 회사가 자기 작업으로 잰 값입니다.

Asana · AI 팀원 기능

30% 이상 감소

작업 완료까지 걸리는 지연 시간이 줄었고, 에이전트 턴당 추론은 최대 2.5배 빨라졌습니다.

HubSpot · CRM 평가 모음

92.8% 평균

세 번 실행한 평균입니다. 테스트한 모델 가운데 작업을 가장 빨리 끝냈고, 적중률이 가장 높았으며, 오탐률이 가장 낮았습니다.

AlphaSense · 문서 질의

0.84 / 0.76

400개 질의에서 Haiku 4.5(0.76)보다 높았습니다(Haiku 5.5, 0.84). 차이는 통계적으로 유의했습니다.

Box · 기업 콘텐츠 분석

+11 점

Haiku 4.5보다 11점 높았고, 지연 시간은 약 절반이었습니다. 비용 보고서와 주간 검토 같은 대량 분석에 쓰일 수 있다고 봤습니다.

(5) 안전성

정렬은 Haiku 4.5보다 나아졌고, 안전장치는 작업 범위에 맞췄습니다

정렬

거의 모든 정렬 평가에서 Haiku 4.5보다 나아졌습니다. 잘못된 행동이 적었고, 남용에 협력하려는 경향도 낮았습니다. 평가 방법과 결과는 시스템 카드에 있습니다.

사이버 안전장치

Haiku 4.5보다 엄격하지만, 최근 다른 모델들보다는 덜 엄격합니다. Sonnet 5.5 기준보다 넓은 범위의 방어 작업을 허용하고, 침투 테스트처럼 공격에 쓰일 수 있는 기법은 막습니다.

생물 안전장치

Sonnet 5, Sonnet 5.5, Opus 5와 같은 기준입니다. 연구 목적의 생물학 질문은 허용하고, 해를 끼칠 가능성이 높다고 판단한 요청은 제한합니다.

검증 프로그램

더 넓은 생물학이나 사이버 작업이 필요한 기관은 생명과학 검증 프로그램과 사이버 검증 프로그램에 신청할 수 있습니다.
