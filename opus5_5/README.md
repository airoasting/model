# Opus 5.5의 획

Claude Opus 5.5가 1인칭 합니다체로 자기 이야기를 들려주는 한 페이지 사이트. AI 강의 수강생이 5분 안에 끝까지 스크롤하도록 만들었다.
분류는 Prototype(강의용 콘텐츠)이고, 목표 등급은 9.5점이다.

## 파일
- `index.html`: 사이트 전체. HTML, CSS, JS가 한 파일에 있고 외부 이미지는 쓰지 않는다. 폰트만 Google Fonts에서 불러온다.
- `COPY.md`: 모든 문구의 정본. 문구를 고칠 때는 여기부터 고치고 `index.html`에 옮긴다.
- `review/SCORES.md`: 다관점(RED, SILVER, BLUE, GOLD, 시인) 채점 기록과 의견이 부딪힐 때의 판정 원칙. 다시 윤문할 때 같은 방식으로 돌린다.

## 구조
- 7장 + 수묵화 + 마지막 장면 + 지은이의 말.
- 시 「획」 일곱 줄이 장마다 한 줄씩 자모 입자로 날아와 조립된다. 데스크톱은 왼쪽 세로쓰기, 모바일은 상단 띠.
- 핵심 효과 `assemble()`: 목표 글자를 화면 밖 캔버스에 그리고 픽셀 좌표를 뽑은 뒤 자모 입자를 그 자리로 날린다. 2장 숫자와 마지막 장면이 같이 쓴다.
- 보조 인터랙션: 3장 종목 경주, 4장 두 시계, 5장 군더더기 덜어내기, 6장 비교 막대.
- 수묵화: 한지 바탕과 먼 산 위에 한자 劃(그을 획) 14획을 획순대로, 붓을 대고 긋고 눌러 맺는 리듬으로 쓴다. 획순과 중심선은 hanzi-writer-data(Make Me a Hanzi)를 따르고, 붓 표현은 코드로 입힌다. 낙관은 'Opus 5.5'.
- `prefers-reduced-motion`이면 입자와 붓 움직임 없이 완성된 글자와 그림만 보인다.

## 고칠 때
- 숫자는 `BENCH`, `CASES` 배열과 본문에 있다. Anthropic 공식 발표(2026.9.22)에 없는 숫자는 넣지 않는다.
- 시를 바꾸면 `.rail-lines`, `.finale-text`, 지은이의 말 `.notes` 세 곳을 같이 바꾼다.
- 새 인터랙션을 넣기 전에 기존 것을 다듬는다.

## 완성 기준
- 소리 내어 읽어 걸리는 문장이 없다. 금지 표현(광고 문구, 진행자 말투, 번역투, 대시, 이모지)이 없다.
- 처음 나오는 용어마다 풀이가 있다.
- 7장이 줄지 않고 온전히 들어가 있다.
- 휴대폰 세로 화면에서 가로 스크롤이 생기지 않는다.
