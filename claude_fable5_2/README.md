# Claude Fable 5.2 · 요청 한 줄이 이 페이지가 되기까지

Claude Fable 5.2가 자기를 소개하는 한 페이지 사이트. 스크롤을 내리면 입자가 장면마다 다른 모양으로 모이며 이야기가 이어진다.
자랑 대신 "요청 한 줄을 받고 한 일"을 순서대로 보여 주는 것이 콘셉트다. 분류는 Prototype(강의용 콘텐츠), 목표 등급은 9.5점.

## 파일
- `index.html`: 사이트 전체. HTML, CSS, JS 한 파일. 외부에서 가져오는 것은 Google Fonts뿐이다.
- `README.md`: 이 문서.

## 구조
장면 아홉 개. 각 장면은 긴 구간(`.scene`) 안에서 본문(`.pin`)이 화면에 붙어 있고, 그 사이 스크롤이 줄(`[data-at]`)을 하나씩 켠다.

| 번호 | 장면 | 입자 모양 | 내용 |
|---|---|---|---|
| 00 | 표지 | 5.2 글자 | 제목, 출시일 |
| 01 | 요청 | 한 줄과 커서 | 스크롤로 타이핑되는 요청문 |
| 02 | 읽기 | 종이 아홉 장 | 먼저 답한 모델 아홉, 작업 지침 |
| 03 | 계획 | 나무 | 주제, 형식, 기준 |
| 04 | 도구 | 점과 선 | 쓴 도구, 입자를 그리는 방법 |
| 05 | 검증 | 좁아지는 소용돌이 | 확인한 것과 고친 것 |
| 06 | 성적 | 막대 다섯 개 | Anthropic 발표의 벤치마크 |
| 07 | 한계 | 가운데가 빈 고리 | 숫자, 평가, 기억, 오류 |
| 08 | 인계 | 수평선과 해 | 전체 벤치마크 표, 확인된 정보 |

허브 카드는 `../index.html`의 `#card-fable52`(Anthropic 줄 맨 오른쪽)이고, 진입 애니메이션은 `settle()`이다.

문구는 korean 스킬로 윤문했다(2026. 11. 10, 정량 8.5 → 10.0, 변경률 약 25%). 문구를 고치면 합니다체와 숫자 보존을 다시 확인한다.

## 고칠 때
- 장면의 색, 위치, 크기, 밝기: 스크립트의 `SC` 표. 한 줄이 한 장면이고 순서가 `.scene` 순서와 같아야 한다. 글자 강조색은 각 `.scene`의 `--a`, `--b`.
- 입자 모양: `makeShapes()` 안의 `build()` 아홉 개. 장면을 더하면 `SC`, `build()`, `.scene`, `.rail` 네 곳을 함께 고친다.
- 줄이 켜지는 시점: 각 요소의 `data-at`(장면 안 진행도 0~1).
- 좁은 화면에서 숨길 줄은 `.m-hide`, 낮은 화면에서 숨길 줄은 `.opt`.

## 사실 규칙
- 숫자는 Anthropic 발표 "Introducing Claude Fable 5.2 and Claude Mythos 5.2"(2026. 11. 9, https://www.anthropic.com/claude-fable-and-mythos-5-2)에서만 가져온다. 출시일, 벤치마크 표 15줄(시험 14개), 06 장면의 막대 네 줄, 입자 막대 다섯 개(FrontierCode 2.0)가 모두 여기서 왔다.
- 표의 조건(effort, Mythos 점수, 안전장치 없이, 각주 †‡)을 지우지 않는다. 1위가 아닌 두 곳(AutomationBench, AA-Briefcase Elo)을 본문에 적어 둔다.
- 막대는 0에서 시작하고 높이는 점수에 비례한다.
- 05 검증 장면의 목록은 실제로 확인한 것만 적는다. 다시 검증하면 목록도 다시 쓴다.

## 검증
- 주소 끝에 `?still`을 붙이면 동작 줄이기 모드가 된다. 모든 글이 처음부터 보이고 모양은 스크롤 위치에서 바로 바뀐다.
- 2026. 11. 10 확인: 1024x768과 375x812에서 콘솔 오류 없음, 375px에서 가로 스크롤 없음, `?still`에서 숨은 줄 0개.

## 아직 하지 않은 것
- 실제 휴대폰(iOS Safari, Android Chrome)에서 보지 않았다. 브라우저의 휴대폰 크기 흉내로만 확인했다.
- OG 이미지가 없다.
