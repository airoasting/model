# Fable 5.1 우화집

Claude Fable 5.1이 자기를 소개하는 한 페이지 사이트. 한 권의 우화집 형식이다. AI 강의 수강생이 휴대폰으로 5분 안에 보도록 만들었다.
분류는 Prototype(강의용 콘텐츠), 목표 등급은 9.5점. 허브 `../index.html`의 세 번째 카드다.

## 파일
- `index.html`: 사이트 전체. HTML, CSS, JS 한 파일. 외부는 Google Fonts뿐이다.
- `DESIGN_PROMPT.md`: 제작 프롬프트 확정판. 사실 규칙과 디자인 토큰의 정본.
- `COPY.md`: 문구 정본(윤문 2차). 문구는 여기부터 고친다.
- `review/PROMPT_v1_BLACK.md`: 1차 초안.
- `review/SCORES.md`: RED, SILVER, BLUE, GOLD 비평 점수와 충돌 판정 원칙.

## 구조
책장을 옆으로 넘기는 한 권의 책이다. 표지(반가죽 제본, 라이브 마블링) → 헌사와 목차 → 우화 6편(펼침면: 왼쪽 이야기와 교훈, 오른쪽 기록) → 지은이 소개 → 뒷면지(마블링) → 뒤표지(책을 덮은 뒤: 타이포그래피와 복사할 요청 문장).

- 넓은 화면은 두 쪽 펼침면, 좁은 화면은 한 쪽씩. 쪽 원고는 `#store`에 순서대로 두고, 스크립트가 책장(`.leaf`)에 앞뒷면으로 묶는다.
- 넘기기: 쪽 가장자리를 누르거나 끌기, 옆으로 쓸기, 화살표 키, 아래 막대(목차 / ← / →). 목차 항목을 누르면 그 화까지 연달아 넘어간다.
- 쪽 안 글이 넘치면 글자를 13px까지 줄이고, 그래도 넘치면 쪽 안에서 스크롤한다.

- 마블링 `class Marble`: 물감 방울과 빗살을 다각형 변환으로 계산한다(Jaffer, Mathematical Marbling). 같은 중심의 방울을 여러 번 나눠 떨어뜨려 번지는 모습을 그린다. 누르면 물감, 끌면 빗살. 동작 줄이기나 숨은 탭에서는 최종 무늬를 한 번에 그린다.
- 3화 성적 `TESTS`: 기본 세 시험을 막대로, 전체 9개 점수는 접힌 표로.

## 고칠 때
- 숫자는 `DESIGN_PROMPT.md` 4절의 정본에서만 가져온다. Anthropic 발표(2026. 9. 1)에 없는 숫자는 넣지 않는다.
- 이야기와 기록 사이에 인과어("그래서", "덕분에")를 쓰지 않는다.
- 1~5화에는 "저"를 쓰지 않는다. 6화 빈 교훈과 정오표, 지은이 소개, 뒤표지에서만 쓴다.
- 새 모델이 나오면 6화 정오표의 "가장 새 모델" 항목을 고친다.

## 완성 기준
- 첫 화면이 스크롤 없이 완성돼 보인다.
- 모든 숫자에 발표 기준과 조건어(약, 최대, 기존)가 붙어 있다.
- 휴대폰 세로 화면에서 가로 스크롤이 없고, 마블링이 세로 스크롤을 막지 않는다.
