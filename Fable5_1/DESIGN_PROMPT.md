# Claude Fable 5.1 우화집 · 제작 프롬프트 (확정판)

원 요청: "너를 소개하는 최대한 화려한 웹페이지를 만들어줘. 멀티 페르소나 동원해서 이 프롬프트를 구체화해줘."
1차 초안(`review/PROMPT_v1_BLACK.md`)을 RED, SILVER, BLUE, GOLD 네 비평가가 읽고 고친 결과다. 판정 기록은 `review/SCORES.md`.

- 분류: Prototype(강의용 콘텐츠). 목표 9.5점.
- 독자: AI 강의를 듣는 40대 비개발자 팀장. 강사가 띄운 링크를 휴대폰으로 5분 동안 본다.
- 한 가지 일: 이 모델이 무엇이고 무엇을 모르는지 이야기로 기억하게 하고, 마지막에 요청 문장 하나를 복사해 가게 한다.

## 1. 콘셉트

Fable은 우화다. 사이트 전체를 한 권의 우화집으로 만든다. 지은이, 삽화가, 제본가는 Claude Fable 5.1이다.

- 우화 여섯 편의 주인공은 동물과 나무다. 동물에게 모델 이름을 붙이지 않는다(비유가 암호가 된다).
- 1~5편에는 "저"가 나오지 않는다. 6편의 빈 교훈에서 처음 "저"가 나오고, 판권면에서 "앞의 동물들은 모두 저였습니다"로 정체를 밝힌다.
- 감정선: 호기심(두 나무) → 가벼움(당나귀) → 자랑과 겸손(거북) → 끈기(개미) → 신뢰(문지기) → 고백(부엉이).
- 우화마다 세 칸: 이야기(지어낸 것) / 교훈(한 문장짜리 삶의 진실) / 기록(Anthropic 발표의 사실과 숫자).
- 이야기와 기록 사이에 "그래서", "덕분에" 같은 인과어를 쓰지 않는다. 목차에서 "이야기는 지어낸 것이고, 기록은 발표에서 옮겼습니다"라고 밝힌다.

## 3. 사실 규칙 (RED)

- 모든 숫자의 주어는 "Anthropic 발표에 따르면"이다. 스스로 매긴 평가는 쓰지 않는다.
- 비교 대상 네 모델은 발표가 고른 것이라고 밝힌다. Opus 5.5 페이지의 숫자와 섞지 않는다(CursorBench 3.2.0과 4.0, GDPval-AA v2와 v2.1로 판이 다르다).
- Mythos 5.1의 60.9%는 막대에 넣지 않고 각주로만 쓴다.
- "발표 없음" 칸은 0점 막대로 그리지 않고 글자로 적는다.
- 막대 눈금은 시험마다 따로 잡는다. Elo는 퍼센트와 같은 축에 두지 않는다.
- "단가를 내렸다"라고 쓰지 않는다. 입력과 출력 단가는 Fable 5와 같고, 내린 것은 캐시 읽기다. 25%에는 "약", 45%에는 "최대 약"을 붙인다.
- 오탐 감소를 "더 안전해졌다"로 바꿔 쓰지 않는다. 기준(Fable 5 출시 때 안전장치, 이전 안전장치)을 붙인다.
- 과학 사례는 "발표에 실린 연구 사례"로 쓰고, 걸린 기간은 쓰지 않는다. 조건어(약, 최대, 기존)를 빼지 않는다.
- "Opus보다 위 등급", "가장 뛰어난"을 단정하지 않는다. Opus 5.5와 우열을 말하지 않는다. "제가 나온 뒤에 새 모델이 나왔다"까지만 쓴다.
- 1편에서 "안전장치만 다르다"의 "만"을 쓰지 않는다. 쓸 수 있는 곳도 다르다.

- 팔레트: 책 천 #173229, 금박 #C9A45C / #EFD994 / #6E5220, 본문 종이 #E8EBE3(차가운 회백), 먹 #1A1F1C, 책상 #0F1A17. 마블링 물감 프러시안 #1D3F6E, 황토 #C8962E, 꼭두서니 #8A2B3D, 흑녹 #0F1A17, 옅은 회백 #D9DCCF.
- 서체: 제목 Hahmlet, 본문 Gowun Batang, 라틴 금박 IM Fell English SC, 모델 ID와 숫자 JetBrains Mono. 서체당 굵기 2개까지.
- 금박은 두 곳에만: 책등 제목, 기록의 큰 숫자. 광택은 CSS 변수 하나로 움직인다(데스크톱은 포인터, 휴대폰은 스크롤). 막대는 금박이 아닌 단색.
- 우화는 데스크톱에서 펼침면(왼쪽 이야기, 오른쪽 기록, 가운데 제본 그늘). 왼쪽 쪽 머리글은 책 이름, 오른쪽은 우화 제목. 휴대폰에서는 쪽이 세로로 쌓인다.
- 머릿글자는 우화 첫 글자에만. 가름끈은 고정 요소로 현재 우화 번호를 보여 주고, 누르면 목차로 간다.
- 무늬 위에 글자를 직접 올리지 않는다. 모든 글은 종이 딱지 위에 둔다.
- 풀이나 인용에 왼쪽 띠(세로 선) 강조를 쓰지 않는다.
- 본문 뒤에 움직이는 배경을 깔지 않는다. 마블링은 앞 표지와 뒷면지에만.

## 6. 마블링

- 방식: 벡터 다각형 마블링(Jaffer의 수학적 마블링). 물감 방울 변환 P' = C + (P - C)·√(1 + r²/|P - C|²), 빗살 변환 P' = P + (αλ/(d + λ))·M. 선분이 길어지면 원래 좌표에서 쪼갠 뒤 변환해 곡선을 정확히 유지한다.
  - SILVER는 WebGL 핑퐁 텍스처를 제안했다. 벡터 방식이 어떤 해상도에서도 경계가 선명하고 한 파일로 검증하기 쉬워 벡터를 택했다. 정점 폭증 대응은 SILVER 안을 따른다(방울 수 상한, 다각형당 정점 상한, 화면 밖 선분은 쪼개지 않음, 가장 오래된 층을 바탕색으로 흡수).
- 물감이 번지는 연출: 같은 중심의 방울은 합성하면 넓이가 더해진다. 작은 방울을 여러 프레임에 나눠 떨어뜨려 퍼지는 모습을 정확하게 그린다.
- 자동 연출: 고정 시드로 물감 방울 약 14개와 빗살 2회를 4초 안에 그리고 멈춘다.
- 조작: 누르면 물감, 끌거나 옆으로 쓸면 빗살. `touch-action: pan-y`로 세로 스크롤을 지킨다. "새 종이" 버튼. 조작 버튼은 최소 44px.
- 동작 줄이기: 같은 시드의 최종 무늬를 한 번에 계산해 정지 화면으로 보여 주고 금박 광택을 끈다.
- 화면 밖이나 숨은 탭에서는 그리기를 멈춘다. DPR은 1.5로 제한.

## 7. 독자 (GOLD)

- 영어 시험 이름 대신 한국어로 무엇을 재는지 적고, 원래 이름은 작게.
- 첫 등장 용어에 한 줄 풀이: 토큰, 캐시 읽기, 에이전트 작업, Elo, 오탐, 익스플로잇.
- 원화 환산이나 예시 금액을 지어내지 않는다.
- 마지막에 복사 버튼이 달린 요청 문장 2개와 쓸 수 있는 곳 한 줄.

## 8. 문체

- 본문은 합니다체. 버튼과 안내는 해요체.
- 과장어, 줄표, 이모지, 광고 문구 금지. "A가 아니라 B" 문형 반복 금지. 교훈 문형이 겹치지 않게.
- 제본 전문 용어(내지, 장정, 보급판 등)는 화면 문구에 쓰지 않는다. 책 형식은 모양으로 보여 주고, 말은 쉽게 쓴다.
- 목차는 제목과 한 줄 요약만 둔다. 읽는 방법을 안내하는 문장은 넣지 않는다.

## 9. 기술

- 빌드 없는 단일 HTML. 외부는 Google Fonts뿐.
- 키보드 조작(탭 UI는 화살표 키), 보이는 포커스, `prefers-reduced-motion`.
- 휴대폰 세로 화면에서 가로 스크롤 없음.
- 허브 카드: 책 천 #173229와 금박 한 줄. 기존 두 카드의 주홍, 남보라와 섞지 않는다.
